# RC Airplane

An ongoing personal engineering project to design and build an RC airplane from scratch.

The project is currently in the electronics development phase. The Arduino based control electronics and nRF24L01 wireless communication system are being developed for the airplane, alongside the propulsion electronics.

## Project Overview
This project documents my work on designing and building a scratch built RC airplane. Rather than purchasing a complete aircraft, I'm developing its different systems myself.

The goal is to gradually develop a working aircraft while gaining practical experience with electronics, embedded programming, and wireless communication. I also want to expand my skills in PCB design and 3D modeling throughout the project.

## Project Status

**Status:** In progress  
**Build approach:** Designed and built from scratch  
**Current focus:** Electronics development

The airplane itself is not yet complete. This repository documents the learning, experiments, code, and integration work as the project develops.

## Electronics

The airplane's electronic systems are organized in the [Learning-Projects](Learning-Projects/) folder.

- [RC Wireless Communication](Learning-Projects/nRF24L01/README.md), Arduino and nRF24L01 wireless control system.
- [Propulsion System](Learning-Projects/Propulsion-System/README.md), propulsion electronics and motor control development.

## Challenges and Lessons Learned
* Independent Development

One of the main challenges has been developing the project without a dedicated mentor or direct technical guidance. I've had to rely on video tutorials, and independent research to understand the concepts and make development decisions. This has pushed me to become more independent in learning and problem solving.

* Project Funding

Another challenge is funding the project independently. All components, materials, and equipment are purchased using my own money. This means I have to plan purchases carefully, and work within a limited budget
