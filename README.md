# RC Airplane

An ongoing personal engineering project to design and build an RC airplane from scratch.

The project is currently in the electronics development phase. The Arduino based control electronics and nRF24L01 wireless communication system are being developed for the airplane, alongside the propulsion electronics.

## Project Status

**Status:** In progress  
**Build approach:** Designed and built from scratch  
**Current focus:** Electronics development

The airplane itself is not yet complete. This repository documents the learning, experiments, code, and integration work as the project develops.

## Systems

### [nRF Wireless Communication](nRF/README.md)

Documentation for the nRF24L01 wireless communication system and its Arduino implementation. This system is being developed for the airplane.

### [Propulsion System](Propulsion-System/README.md)

Documentation for the propulsion electronics, including MOSFET related learning and motor control development.

## Learning and Application

See [Learning and Application](Learning-and-Application.md) for learning notes and video references showing concepts explored during development.

## Development Process

1. Learn and experiment with individual electronic components.
2. Develop the Arduino and wireless communication system.
3. Develop the propulsion electronics.
4. Integrate the systems into the airplane.
5. Test, troubleshoot, and refine the aircraft.

## Note

This is a work in progress. Documentation will be expanded as the design, hardware, code, and testing develop. Learning activities, tested circuits, and completed integrations will be identified separately so the repository accurately reflects the project's progress.
